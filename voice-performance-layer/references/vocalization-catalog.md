# 非言语发声完整图谱 — Vocalization Catalog

按类别和情绪强度分级。每个条目包含：
**声音名称 → 物理机制 → 情绪映射 → 精确描述 → Prompt 标记**

---

## 一、呼吸类 (Breathing Vocalizations)

### 叹气 (Sighs)

| 类型 | 物理机制 | 情绪 | 描述 | 标记 |
|------|---------|------|------|------|
| 轻叹 | 缓慢呼出，口微张 | 无奈/小失望 | 鼻腔呼出持续 1s，嘴角微垂 | `[soft sigh]` |
| 深叹 | 先深吸后重呼出 | 疲惫/彻底放弃 | 胸腔先膨胀再重重塌下，呼出 2s 带声 | `[heavy sigh]` |
| 颤叹 | 呼出时声带微震 | 悲伤/哭泣前兆 | 呼出气流断续，像在发抖 | `[shaky sigh]` |
| 释放叹 | 长时间屏息后呼出 | 解脱/紧张释放 | 闷声 "呼——" 伴肩膀下沉 | `[exhale of relief]` |

### 吸气 (Inhalations)

| 类型 | 情绪 | 描述 | 标记 |
|------|------|------|------|
| 倒吸凉气 | 惊恐/疼痛 | 牙缝间急速吸入，发出嘶声 | `[sharp intake through teeth]` |
| 准备深吸 | 即将说重要的话 | 明显的胸腔扩张，0.5s停顿后开口 | `[deep breath in]` |
| 抽泣性吸气 | 哭泣中 | 短促、痉挛性的多次吸气 | `[hitched breathing]` |
| 惊吓吸气 | 突然受惊 | 快速、大声的一次吸入 | `[gasp]` |

### 喘息 (Panting)

| 类型 | 情绪/状态 | 描述 | 标记 |
|------|---------|------|------|
| 运动喘息 | 体力消耗 | 张嘴快速呼吸，15-20次/min | `[panting, out of breath]` |
| 恐惧喘息 | 极度恐惧 | 浅快呼吸，25+次/min，带颤音 | `[panicked hyperventilating]` |
| 激情喘息 | 激动/亲密 | 深而慢的张嘴呼吸，偶尔带声 | `[heavy breathing]` |

## 二、喉部类 (Throat Vocalizations)

| 声音 | 物理机制 | 情绪映射 | 描述 | 标记 |
|------|---------|---------|------|------|
| 吞咽 | 舌根推压、喉头上升 | 紧张/恐惧/口干 | 可见喉结运动，伴轻微"咕"声 | `[swallow]` |
| 清嗓 | 声带快速闭合排异 | 尴尬/准备发言/不适 | 低沉"嗯哼"声 | `[throat clear]` |
| 哽咽 | 声带痉挛性关闭 | 强忍哭泣 | 声音突然中断，喉部卡住 | `[choke]` |
| 喉咙发紧 | 环甲肌过度收缩 | 压抑情绪 | 说话时声音被挤压变细 | `[voice tightening]` |
| 干呕 | 咽反射 | 恶心/极度厌恶 | 喉部收缩的沉闷声 | `[gag]` |

|------|---------|------|------|
| 啧嘴 | 不满/遗憾/思考 | 舌尖从上颚弹离，发出清脆的"啧" | `[tsk]` |

| 嘟囔 | 犹豫/自言自语 | 嘴巴几乎不动的低声含混 | `[mumbling]` |

## 四、笑声类 (Laughter Types)

| 类型 | 情绪 | 声学特征 | 描述 | 标记 |
|------|------|---------|------|------|
| 轻笑 | 温和开心 | 鼻腔出气，嘴微闭 | 柔和的"呵呵"声 | `[soft chuckle]` |
| 大笑 | 真正开心 | 张嘴、腹肌参与 | 洪亮的"哈哈哈"伴身体震动 | `[hearty laugh]` |
| 苦笑 | 无奈/自嘲 | 一声短促"哈"后无续 | 嘴角上扬但眼睛不笑 | `[bitter laugh]` |
| 冷笑 | 蔑视/嘲讽 | 鼻腔单次出气 | 鼻孔喷出"哼"声 | `[scornful snort]` |
| 尴尬笑 | 社交不适 | 高频短促碎笑 | "嘿嘿嘿"音高偏高 | `[nervous giggle]` |
| 歇斯底里 | 情绪崩溃 | 笑声不受控制 | 笑声和哭声混合 | `[hysterical laughter]` |
| 偷笑 | 暗中得意 | 嘴唇紧闭的振动 | 嘴角抖动，从鼻子漏气 | `[stifled snicker]` |
| 干笑 | 假装开心 | 节奏机械、不自然 | "哈、哈"间距均匀无变化 | `[forced laugh]` |

## 五、哭声类 (Crying Types)

按情绪强度从低到高排列：

| 类型 | 强度 | 声学特征 | 描述 | 标记 |
|------|------|---------|------|------|
| 眼眶湿润 | ★ | 无声，仅呼吸微变 | 鼻腔微酸，眨眼频率增加 | `[eyes welling up]` |
| 无声流泪 | ★★ | 沉默，偶尔吸鼻 | 泪水滑落但不发声，喉部吞咽 | `[silent tears]` |
| 轻声抽泣 | ★★★ | 断续吸气、低声呜咽 | "嗯……嗯……"伴身体轻颤 | `[quiet sobbing]` |
| 哭泣 | ★★★★ | 持续发声、呼吸紊乱 | 声带震动的哭声，断断续续说话 | `[crying]` |
| 嚎哭 | ★★★★★ | 高音量、全身参与 | 张嘴大声哭喊，身体弯曲 | `[wailing]` |

## 使用组合指南

### 情绪-声音搭配表

| 情绪 | 推荐组合（选 2-3 个） |
|------|---------------------|
| 焦虑 | `[swallow]` + `[throat clear]` + `[nervous giggle]` |
| 悲伤 | `[shaky sigh]` + `[quiet sobbing]` + `[voice tightening]` |
| 愤怒 | `[sharp intake]` + `[hiss through teeth]` + `[scornful snort]` |
| 恐惧 | `[gasp]` + `[panicked hyperventilating]` + `[swallow]` |
| 思考 | `[um]` + `[lip smack]` + `[tsk]` |
| 疲惫 | `[heavy sigh]` + `[groan]` + `[panting]` |
| 尴尬 | `[nervous giggle]` + `[throat clear]` + `[forced laugh]` |
| 压抑 | `[swallow]` + `[choke]` + `[silent tears]` |

### 台词中的插入规则

1. **前缀型**：台词前的非言语发声（准备说话）→ 放在引号前
2. **中插型**：台词中间的中断 → 用 `[标记]` 插入台词文本中
3. **后缀型**：台词后的情绪余波 → 放在引号后
4. **替代型**：角色无法说话时 → 非言语发声完全替代台词

```
前缀: [deep breath] "我准备好了。"
中插: "我觉得…… [swallow] ……这不对。"
后缀: "算了吧。" [heavy sigh, eyes closing]
替代: [opens mouth, chokes, shakes head, walks away]
```
